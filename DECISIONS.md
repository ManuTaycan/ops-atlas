# Project decisions

## 2026-10-01 — Initial foundation

| Decision | Rationale |
| --- | --- |
| Keep the repository public. | Make reusable knowledge available to the community. |
| Write repository content in English. | Give the public reference a consistent language. |
| Write for practical administrators. | Readers may know the product while needing exact steps and explanations. |
| Grow from real solved cases. | Avoid speculative content and artificial topic priorities. |
| Read articles directly on GitHub. | Keep the initial publishing path simple; no website is needed now. |
| Keep one canonical location per article. | Avoid divergent copies and unclear updates. |
| Sanitize before any public upload. | Public history can retain information even after a later edit. |

These decisions describe the initial direction. Changes should be recorded here with a date and rationale rather than silently changing the repository's conventions.
