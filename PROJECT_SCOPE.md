# Project scope

OpsAtlas is a public personal knowledge base and reusable community reference, written in English. It serves administrators who understand IT products but may need precise, explained steps rather than memorized syntax or portal paths.

The scope is broad: Microsoft and Windows, Microsoft 365, Entra ID, Intune, Azure, Linux, Proxmox, networking, security, backup and storage, automation, and related administration topics. No topic has artificial priority. Real solved cases determine what is added.

Articles are read directly on GitHub. Each article has one canonical location. Create a topic folder when a real article requires it; do not build empty folder trees, an invented article series, or a generated topic catalog.

Public content must exclude company-internal and customer-specific information. Sanitize before upload, including examples, commands, output, logs, screenshots, and metadata. Do not move private or company notes into this repository without a separate, careful review.

Current scope excludes a documentation website, GitHub Pages, a license decision, CI or workflows, semantic or AI search, a backend, a database, external services, and paid services. These may be considered separately if a real need arises.
